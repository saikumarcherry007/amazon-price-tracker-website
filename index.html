Privacy Policy

1. Introduction

This privacy policy describes how the "Amazon Price Tracker - Link Account" browser extension (the "Extension") collects, uses, and handles data. The Extension operates within Google Chrome and Microsoft Edge browsers.

2. Data Collected

  • Amazon session cookies: The Extension reads at- named cookies from the user's browser when on Amazon domains (.amazon.in, .amazon.com). These cookies authenticate the user's Amazon session and are necessary for the price-tracking functionality.
  • Email address: Users voluntarily provide an email address to link their Amazon account to the Extension's backend service.
  • Machine/device information: When linking an account, the Extension collects: browser user-agent string, extension version, and a machine ID (generated as "chrome-ext-" + timestamp). This information helps identify and restore the user's account.

3. How Data Is Used

  • The collected cookies and email are sent securely to our backend service via encrypted API calls.
  • The backend monitors price changes for the user's Amazon cart and wishlist and sends alerts when prices drop below user-defined targets.
  • Data is used exclusively to enable the price-tracking and alert functionality.
  • The "Refresh Cookies" feature periodically re-sends updated cookies to maintain an active session.

4. Data Storage

  • All user data (cookies, email, machine ID, metadata) is stored securely in a cloud database.
  • Data is stored in accordance with the cloud provider's data handling practices and regional storage options.
  • The Extension's local storage (browser) stores: the linked email address and timestamp, used to restore the Extension state on reinstall.

5. Data Retention

  • Data is retained until the user disconnects their account using the Extension's "Disconnect" feature in the popup.
  • Upon disconnection, the associated cookies, email, and machine ID are removed from our backend.
  • If the Extension is uninstalled without disconnecting, data may persist until the user disconnects via the Extension UI or contacts the developer.

6. User Rights

  • Disconnect: Users can click "Disconnect Amazon Account" in the Extension popup to immediately remove their linked account data and clear local storage.
  • Data deletion: Users may request complete data deletion by contacting the developer via the email below; all associated personal data will be removed within 30 days.
  • Export: Users can view their linked email and disconnection status at any time via the Extension popup.

7. Third-Party Services

The Extension uses secure cloud infrastructure for backend data storage and price-monitoring automation. All data processing occurs either within the browser or via our secure backend, both of which are necessary for the core functionality.

The Extension does not sell user data to third parties.

8. Children's Privacy

The Extension is not directed to children under 13 and does not knowingly collect personal data from children. If you are a parent or guardian and believe your child has provided data, please contact us.

9. Changes to This Policy

We may update this privacy policy from time to time. We will notify users of material changes by posting the new policy on this page. Users are encouraged to review this policy periodically.

10. Contact

For questions or requests regarding this privacy policy or your data, email: privacy@amazonpricetracker.example.
